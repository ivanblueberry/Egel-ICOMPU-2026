# Reporte privado de contenido sensible

Usa este canal para reportar reactivos que pudieran proceder de una aplicación real, documentos confidenciales, datos personales o material incorporado sin autorización.

1. Abre la pestaña **Security** del repositorio.
2. Selecciona **Report a vulnerability** para crear un aviso privado: <https://github.com/ivanblueberry/Egel-ICOMPU-2026/security/advisories/new>.
3. Indica únicamente los identificadores o rutas necesarios para localizar el problema. No pegues el contenido presuntamente confidencial si basta con señalarlo.

Si el reporte privado no está habilitado, contacta primero a [@ivanblueberry](https://github.com/ivanblueberry) sin publicar los detalles. Puede abrirse una issue pública que solo solicite un canal de contacto, pero no debe contener la pregunta, respuesta, fotografía o transcripción investigada.

El material cuestionado se retirará de la distribución pública mientras se revisan su procedencia y licencia. Los errores académicos ordinarios pueden reportarse mediante una issue normal.
