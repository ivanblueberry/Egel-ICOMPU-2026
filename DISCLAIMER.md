# Aviso de independencia y límites de uso

Este repositorio es una iniciativa educativa independiente. No pertenece al Centro Nacional de Evaluación para la Educación Superior, A.C. (Ceneval), no ha sido revisado ni autorizado por esa institución y no debe presentarse como material oficial.

Las denominaciones **Ceneval**, **EGEL Plus** e **ICOMPU** se utilizan únicamente para identificar de manera descriptiva la evaluación a la que se refiere el material. Las marcas, documentos oficiales y demás obras citadas pertenecen a sus respectivos titulares. El repositorio no incluye el PDF oficial; únicamente enlaza la copia publicada por Ceneval.

La teoría, los textos de práctica, los ejemplos y los reactivos de este proyecto fueron creados como material independiente. No deben incorporarse contenidos memorizados, fotografiados, transcritos, reconstruidos o descritos a partir de una aplicación real. Las [normas de conducta de Ceneval](https://ceneval.edu.mx/comportamiento-etico-del-sustentante/) prohíben divulgar componentes de sus instrumentos incluso sin fines comerciales.

El banco de práctica no cuenta con calibración psicométrica. Sus porcentajes no equivalen al índice Ceneval, no predicen el nivel de desempeño oficial y no garantizan aprobar. Cada persona debe consultar las fuentes oficiales vigentes para fechas, modalidades, materiales permitidos, estructura y condiciones de aplicación.

Este aviso ofrece información general sobre las decisiones editoriales del proyecto y no constituye asesoría jurídica.
