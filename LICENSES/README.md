# Alcance de las licencias

Este repositorio utiliza licencias separadas según el tipo de obra:

- **CC BY-SA 4.0:** `README.md`, `DISCLAIMER.md`, `CONTRIBUTING.md`, `docs/`, `guia/`, `checks/`, `dist/` y demás contenido educativo o editorial original.
- **MIT:** programas y pruebas dentro de `tools/` y `tests/`.

Los archivos de `.github/` pueden reutilizarse bajo MIT. Las marcas, enlaces, citas, nombres de productos y obras de terceros no quedan relicenciados por este repositorio; conservan las condiciones de sus titulares.

Salvo que un archivo indique otra cosa, la atribución solicitada para el contenido educativo es: “Guía abierta EGEL Plus ICOMPU, @ivanblueberry, CC BY-SA 4.0”, con enlace al repositorio e indicación de cambios.
